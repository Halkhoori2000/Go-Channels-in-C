Channels. In C.

A complete Go-style channel primitive built with POSIX pthreads — buffered and unbuffered, blocking and non-blocking, with a multi-channel select that sleeps until any channel is ready.

How a Channel Works

Sender Thread
channel_send(ch, data)
blocks if buffer full
→
mutex + condvar
Receiver Thread
channel_receive(ch, &data)
blocks if buffer empty

Each channel holds a circular FIFO buffer, a mutex protecting all state, a send condvar (wakes receivers) and a receive condvar (wakes senders). Unbuffered channels (size=0) force rendezvous: the sender blocks until a receiver is present.

API

channel_create(size)
Create a buffered (size > 0) or unbuffered (size = 0) channel. Allocates mutex, condvars, and semaphore lists.
→ channel_t*
channel_send(ch, data)
Blocking send. Waits if buffer is full. Wakes a waiting receiver and any select callers on success.
→ SUCCESS | CLOSED_ERROR | GEN_ERROR
channel_receive(ch, &data)
Blocking receive. Waits if buffer is empty. Wakes a waiting sender and any select callers on success.
→ SUCCESS | CLOSED_ERROR | GEN_ERROR
channel_non_blocking_send/receive
Returns CHANNEL_FULL / CHANNEL_EMPTY immediately instead of blocking. Used internally by channel_select.
→ SUCCESS | CHANNEL_FULL | CHANNEL_EMPTY | CLOSED_ERROR
channel_select(list, count, &idx)
Go-style select. Registers a semaphore on each candidate channel, loops non-blocking attempts, sleeps on sem_wait until any channel posts. Sets selected_index on return.
→ SUCCESS | CLOSED_ERROR | GEN_ERROR
channel_close / channel_destroy
Close broadcasts to all blocked threads (CLOSED_ERROR). Destroy frees all memory; returns DESTROY_ERROR if called on an open channel.
→ SUCCESS | CLOSED_ERROR | DESTROY_ERROR

Key Design Decisions

🔒

Mutex + Condvar Blocking

All state (buffer, open flag) is protected by a single mutex per channel. Blocking send/receive use pthread_cond_wait inside a while loop to handle spurious wakeups.

🔔

Semaphore-Based Select

Each channel_select call creates one sem_t and registers it in every candidate channel's notification list. When a channel becomes ready, it posts all registered semaphores — waking every waiting select.

📡

Broadcast on Close

channel_close uses pthread_cond_broadcast (not signal) and posts all select semaphores to wake every blocked caller simultaneously with CLOSED_ERROR.

♻️

Circular FIFO Buffer

The underlying store is a power-of-2 circular buffer with head/tail indices — O(1) enqueue and dequeue without dynamic allocation after creation.

Channel Struct

typedef struct {
    buffer_t        *buffer;           /* circular FIFO, size=0 → unbuffered */
    pthread_mutex_t  mutex;
    pthread_cond_t   send;             /* signalled when item added (wakes receivers) */
    pthread_cond_t   receive;          /* signalled when item removed (wakes senders) */
    bool             open;
    list_t          *select_recv_sems; /* sem_t* ptrs for select(RECV) callers */
    list_t          *select_send_sems; /* sem_t* ptrs for select(SEND) callers */
} channel_t;

/* select entry — one per channel in a channel_select call */
typedef struct {
    channel_t     *channel;
    enum direction dir;   /* SEND or RECV */
    void          *data;
} select_t;
